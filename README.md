# 3×3 Urteilskompetenz

Web-App für das 3×3-Format zur Förderung der Urteilskompetenz im Politik-Wirtschaft-Unterricht.

## Erste funktionsfähige Version

- Auswahl eines Unterrichtsbereichs
- drei Beurteilungsaufgaben im AB III
- Tabelle mit den Spalten **Beurteilungsaufgabe**, **Pro** und **Contra**
- zufällige Verteilung von 15 Schülerinnen und Schülern
- jede Person wird pro 3×3-Runde genau einmal zugeteilt
- erneutes Mischen per Knopfdruck
- mobil nutzbare Oberfläche

Die App liegt zunächst als einzelne `index.html` ohne externe Abhängigkeiten vor.
